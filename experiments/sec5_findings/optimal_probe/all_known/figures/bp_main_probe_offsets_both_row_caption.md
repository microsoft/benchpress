**Main 84-model probe experiment, evaluated by MedAE and MedAPE.** Probe orderings are selected using MedAE on the original April 30, 2026 matrix, exactly as for the main five-probe MedAE results. For each target model, the other 83 models retain their observed scores, while only the target's available probe scores are revealed. BenchPress (rank 2) and offsets only (rank 0) are evaluated on the same unrevealed observed cells at each requested budget. MedAPE is the median of absolute prediction error divided by the absolute true score, multiplied by 100; lower is better, and zero true scores are excluded. Requested probes need not all have reported scores, and test cells change as more scores are revealed. This is the main 84-model setup, separate from the 59/25 held-out-model validation.
Panels (a,b) show MedAE in score points; panels (c,d) show MedAPE (%). Both metrics use the same MedAE-selected probe orderings.
