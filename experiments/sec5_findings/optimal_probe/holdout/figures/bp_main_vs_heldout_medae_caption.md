**Main and held-out probe experiments.** Top: probe selection and evaluation on the main 84-model matrix; each target is predicted using the other 83 model rows and its available probe scores. Bottom: probes selected on 59 models are evaluated on 25 held-out models, one target at a time. Left: cost-unaware greedy; right: cost-aware greedy. All panels show pooled median absolute error (MedAE, lower is better), using the original MedAE-selected probe orderings. Methods share the same revealed scores and test cells within each panel at each budget. The settings use different probe sets and evaluation cells. Requested probes may be unavailable, and newly revealed scores leave the test set. All four panels compare BenchPress with offsets only, which removes the two latent factors.
