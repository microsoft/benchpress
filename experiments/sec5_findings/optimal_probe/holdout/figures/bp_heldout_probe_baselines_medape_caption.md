**Predictor comparison on 25 held-out models.** Greedy probes are selected using 59 of the 84 models in the April 30, 2026 score matrix (split seed 42). For each held-out target, predictors use those 59 model rows plus the target's available scores among the first $k$ selected probes. The other held-out rows remain hidden. Curves show median absolute percentage error (MedAPE, lower is better) pooled over the target models' remaining observed scores. BenchPress, offsets only (rank 0), and logit-space model mean use the same available probe scores and test cells at each budget. Requested probes need not all have reported scores; revealed probe cells are excluded from the error, so test cells change across budgets. All 25 target models are retained at every budget; the model-mean baseline falls back to the benchmark mean when a target has no available probe scores. Percentage errors use absolute error divided by the absolute true score, multiplied by 100; cells with zero true scores are excluded. Probe orderings remain those selected using MedAE.
