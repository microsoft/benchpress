# Temporal Deployment Stress Test

## Paper mapping

Section 5.3 (Predicting Newly Released Models) in the main body. Previously this experiment lived appendix-only; it was promoted to §5.3 because it answers the third operational question of Section 5 (deployment against a brand-new release).

## Purpose

Test the deployment setting where a new model appears after the current training matrix. The target set is selected by a hard metadata rule before looking at prediction errors: release date on or after DeepSeek R1 (`2025-01-20`), release date no later than GPT-5.1 (`2025-11-13`), and more than 20 observed benchmark scores in the final matrix. For each selected target model, the predictor may use only models released before that target's cutoff date; `k` of the target model's observed benchmark scores are revealed, and BenchPress predicts the remaining observed scores for that model. The shard records all observed scores of the active target model: revealed cells are exact zero-error predictions, hidden cells with finite BenchPress predictions enter MedAPE/MedAE, and hidden cells on benchmarks that have no finite deployment prediction are marked `not_predictable`.

The paper-facing metrics are MedAPE and MedAE, computed with `benchpress.evaluation_harness.compute_prediction_error`.

## How to run

```bash
cd experiments/sec5_findings/temporal_deployment
bash run.sh
```

For a targeted shard:

```bash
python run.py --mode shard --family-key deepseek_r1 --k 10 --seed 0
```

After shards finish:

```bash
python run.py --mode merge
python gen_table.py
python plot.py
```

## Parallel execution

The independent unit is `(target, k, seed)`: 27 hard-rule targets x 3 k values x 10 seeds = 810 shards. `run.py --mode run-all --workers N` runs or reuses those shards in parallel. CPU thread counts should be pinned by `run.sh`; full runs should use a remote CPU machine.

## Inputs

- Canonical score matrix from `benchpress/build_benchmark_matrix`
- Model release dates from the canonical model records
- Current BenchPress default predictor: Logit Bias ALS, rank 2, lambda 0.1

## Outputs

- `results/shards/*.json.gz`: one shard per `(target, k, seed)`, including the target/training model IDs, revealed benchmark IDs, per-cell raw rows for all observed target cells, and shard metrics. Raw rows include `is_revealed`, `is_metric_cell`, and `prediction_source`; revealed cells have `pred=actual`, while non-predictable hidden cells have `pred=null`.
- `results.json`: merged canonical payload with config, hard-rule target definitions, raw predictions, and paper-facing summaries.
- `table.tex`: LaTeX table generated by `gen_table.py`.
- `figures/bp_temporal_deployment_boxplot.{pdf,png}`: main-body candidate box/strip plot generated by `plot.py`.

## Resume / rerun

Existing shards are reused only if their config matches the requested `(target, k, seed)` and protocol version. Stale or incompatible shards are overwritten during `run-all`, while `--mode merge` refuses to merge incompatible or missing shards.
